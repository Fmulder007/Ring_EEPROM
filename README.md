# Ring_EEPROM

Самостоятельная библиотека кольцевой записи EEPROM для Arduino AVR. Пользователь подключает только **Ring_EEPROM.h**, выбирает тип памяти и передаёт обычный объект фиксированного размера.

> **Текущий статус:** первая реализация и host-тесты добавлены. Код прошёл локальную проверку C++11, но ещё требует испытаний на реальных ATmega328P, AT24C32 и AT24C64. Версия **0.1.0** пока не объявляется окончательно испытанной.

## Поддерживаемая память

- **INTERNAL** — внутренняя EEPROM AVR. Ёмкость берётся из **E2END + 1**.

На Arduino AVR макрос `INTERNAL` также используется для выбора внутреннего аналогового опорного напряжения. Библиотека сохраняет этот системный макрос и принимает его значение в `init(INTERNAL, ...)`; собственный код типа памяти внутри библиотеки называется `RING_EEPROM_INTERNAL`.
- **AT24C32** — 4096 байт.
- **AT24C64** — 8192 байта.

Другие семейства в первую версию не входят. Для AT24C32/AT24C64 библиотека сама запускает I²C. Отдельно подключать Wire.h или EEPROM.h в скетче не нужно.

## Быстрый старт

~~~cpp
#include <Ring_EEPROM.h>

struct MyData {
    uint8_t mode;
    uint16_t frequency;
    float swr;
};

const uint16_t DATA_SIGNATURE = 0xA35C;
MyData data = {1, 7100000, 1.25f};
MyData restored = {};

void setup() {
    uint8_t result = Ring_EEPROM.init(AT24C64, DATA_SIGNATURE);
    if (result != RING_OK) {
        // result — конкретный код из единой карты ошибок.
        return;
    }

    result = Ring_EEPROM.write(data);
    if (result != RING_OK) return;

    result = Ring_EEPROM.read(restored);
    if (result != RING_OK) return;
}

void loop() {}
~~~

### Выбор области

Если границы не заданы, используется вся память:

~~~cpp
Ring_EEPROM.init(AT24C64, DATA_SIGNATURE);
~~~

Можно указать начало и конец области. Конечный адрес включительный:

~~~cpp
Ring_EEPROM.init(AT24C64, DATA_SIGNATURE, 512, 4095);
~~~

**init()** определяет устройство и ёмкость, проверяет доступность внешней микросхемы и границы. Размер структуры в init() не передаётся: он определяется отдельно при read() и write() через sizeof.

## Сигнатура

Сигнатура — пользовательская подпись записи. Каждая запись начинается с неё; отдельного общего заголовка кольца нет.

~~~cpp
// Число: размер равен sizeof(тип).
Ring_EEPROM.init(AT24C64, 2222);

// Строка: завершающий нулевой байт не входит в подпись.
const char signature[] = "MY-PROJECT";
Ring_EEPROM.init(AT24C64, signature);

// Массив байтов: учитываются все элементы.
const uint8_t signatureBytes[] = {0x52, 0x45, 0x01, 0xA5};
Ring_EEPROM.init(AT24C64, signatureBytes);

// Для длины, определяемой во время выполнения:
Ring_EEPROM.init(AT24C64, signaturePointer, signatureLength);
~~~

Скалярные подписи копируются внутрь библиотеки. Массивы длиной не более **RING_EEPROM_INLINE_SIGNATURE_MAX** также копируются. Более длинные массивы библиотека хранит по указателю: исходный массив должен оставаться доступным всё время использования объекта. Значение **RING_EEPROM_INLINE_SIGNATURE_MAX** можно увеличить, учитывая расход SRAM.

## Формат записи и кольцо

Каждая запись состоит только из четырёх полей:

~~~text
[СИГНАТУРА][НОМЕР ЗАПИСИ][ДАННЫЕ][CRC]
~~~

Нет дополнительных commit-маркеров, окончаний, отдельных указателей или неподвижных служебных областей. Вся выделенная область участвует в круговом перемещении. После endAddress следующий адрес автоматически равен startAddress.

Размер номера записи выбирается автоматически. Реализация оценивает вместимость как **K = floor(N / L)** и выбирает минимальное число байтов **B**, для которого **256^B > 2K**. Здесь N — размер выделенной области, L — полный размер записи. Для поддерживаемых объёмов достаточно одного или двух байтов.

Шаг между началами записей **P = L + q**; библиотека подбирает минимальную неотрицательную поправку q, чтобы **gcd(P, N) = 1**. q виртуальный: байты-прокладки в EEPROM не записываются.

Новая запись начинается после предыдущей по формуле **(previousStart + P) mod N**. Перед записью библиотека не проверяет содержимое целевого участка: запись выполняется по рассчитанному адресу, затем проверяется чтением обратно.

## CRC

Применяется один потоковый вычислитель. CRC рассчитывается последовательно по сигнатуре, номеру записи и данным:

~~~text
M = S + B + D
~~~

- **M <= RING_EEPROM_CRC8_MAX_BYTES** — CRC-8, одно байтовое поле.
- **M > RING_EEPROM_CRC8_MAX_BYTES** — CRC-16, два байта.
- CRC-32 не используется.
- Порог по умолчанию — 30 байт.

Полиномы по умолчанию:

~~~cpp
#define RING_EEPROM_CRC8_POLY  0xE7
#define RING_EEPROM_CRC16_POLY 0x8D95
~~~

Альтернативы: CRC-8 **0xA6**, CRC-16 **0xFDBF**. Алгоритм MSB-first, без отражения, начальное состояние 0, финальный XOR 0. CRC-16 хранится младшим байтом вперёд.

Контрольные значения для ASCII **123456789**:

| Вариант | CRC |
|---|---:|
| CRC-8 0xE7 | 0x34 |
| CRC-8 0xA6 | 0x62 |
| CRC-16 0x8D95 | 0x4FEF |
| CRC-16 0xFDBF | 0xF336 |

### Чтение и восстановление

**read(data)** сначала проверяет запись потоком и не записывает данные в объект пользователя. Только после совпадения CRC библиотека выполняет второй проход и копирует данные непосредственно в объект.

Если CRC самой новой записи не совпала, проверяются предыдущие записи. Дефайн **RING_EEPROM_FALLBACK_DEPTH** по умолчанию равен 3: всего до четырёх кандидатов вместе с самой новой записью.

- **ERR_READ_NO_RECORD** — сигнатура не найдена.
- **ERR_READ_CRC_FAILED** — сигнатура найдена, но ни один проверенный кандидат не прошёл CRC.

### Проверка после записи

После физической записи **write(data)** вызывает ту же внутреннюю процедуру чтения и CRC-проверки, которая используется в read(), но без копирования данных в пользовательский объект. При несовпадении возвращается **ERR_WRITE_VERIFY**.

### Кэш последней успешной записи

Для ускорения обычной работы библиотека хранит в SRAM адрес и номер последней успешно проверенной записи. При следующем `read()` или `write()` сначала проверяется эта запись; если CRC корректна, полный поиск по EEPROM не нужен.

Если закэшированная запись не проходит проверку CRC или сигнатуры, кэш сбрасывается и выполняется обычный полный поиск с fallback. Успешное чтение или запись обновляет кэш. Повторный `init()` сбрасывает его.

Если `write()` завершается ошибкой, прежний кэш последней успешно проверенной записи не заменяется. Неудачная попытка записи не становится последней успешной записью.

## Дефайны

Значения можно переопределить до подключения Ring_EEPROM.h.

| Дефайн | По умолчанию | Назначение |
|---|---:|---|
| RING_EEPROM_AT24C32_SIZE | 4096 | Ёмкость AT24C32 |
| RING_EEPROM_AT24C64_SIZE | 8192 | Ёмкость AT24C64 |
| RING_EEPROM_I2C_ADDRESS | 0x50 | Адрес внешней EEPROM |
| RING_EEPROM_SDA | A4 | SDA |
| RING_EEPROM_SCL | A5 | SCL |
| RING_EEPROM_I2C_CLOCK | 100000 | Частота аппаратного I²C |
| RING_EEPROM_I2C_TIMEOUT_MS | 25 | Тайм-аут I²C |
| RING_EEPROM_FALLBACK_DEPTH | 3 | Число предыдущих кандидатов |
| RING_EEPROM_CRC8_MAX_BYTES | 30 | Порог CRC-8/CRC-16 |
| RING_EEPROM_CRC8_POLY | 0xE7 | Полином CRC-8 |
| RING_EEPROM_CRC16_POLY | 0x8D95 | Полином CRC-16 |
| RING_EEPROM_IO_BUFFER_SIZE | 32 | Фиксированный буфер |
| RING_EEPROM_INLINE_SIGNATURE_MAX | 16 | Размер встроенной копии сигнатуры |

На ATmega328P штатный аппаратный I²C использует A4/A5. При переопределении SDA/SCL библиотека автоматически переключается на программный I²C.

## Единая карта кодов результата

Все публичные операции возвращают uint8_t: 0 — успех, ненулевое значение — конкретная причина.

| Код | Константа | Причина |
|---:|---|---|
| 0 | RING_OK | Успех |
| 1 | ERR_UNKNOWN_DEVICE | Неизвестный тип EEPROM |
| 2 | ERR_DEVICE_NOT_SUPPORTED | Тип памяти не поддерживается платформой |
| 3 | ERR_I2C_INIT_FAILED | Ошибка запуска/работы I²C |
| 4 | ERR_I2C_NO_RESPONSE | Нет ответа по I²C |
| 5 | ERR_I2C_TIMEOUT | Тайм-аут I²C |
| 6 | ERR_INVALID_ADDRESS | Некорректный адрес |
| 7 | ERR_ADDRESS_OUT_OF_RANGE | Адрес за пределами памяти |
| 8 | ERR_INVALID_RANGE | Некорректный диапазон |
| 9 | ERR_SIGNATURE_INVALID | Сигнатура проверяемой записи изменилась/не совпала |
| 10 | ERR_SIGNATURE_TOO_LONG | Сигнатура не помещается во встроенную копию |
| 11 | ERR_NOT_INITIALIZED | init() ещё не выполнен успешно |
| 12 | ERR_NO_SPACE | Запись не помещается в выделенную область |
| 13 | ERR_READ_FAILED | Ошибка физического чтения |
| 14 | ERR_WRITE_FAILED | Ошибка физической записи |
| 15 | ERR_WRITE_VERIFY | CRC прочитанной после записи записи не совпала |
| 16 | ERR_READ_CRC_FAILED | Записи с нужной сигнатурой не прошли CRC |
| 17 | ERR_READ_NO_RECORD | Запись с нужной сигнатурой не найдена |
| 18 | ERR_INTERNAL_EEPROM_UNAVAILABLE | Внутренняя EEPROM недоступна |
| 19 | ERR_INVALID_ARGUMENT | Некорректный аргумент операции |

## Ограничения первой версии

- Поддерживаются данные фиксированного размера, которые можно копировать как байтовый объект. Указатели, String, динамические контейнеры и структуры с переменным содержимым использовать нельзя.
- В шаблонном API есть проверка `std::is_trivially_copyable` и запрет передавать сам указатель вместо объекта. Однако C++ не позволяет общей библиотеке автоматически перечислить и проверить типы всех полей произвольной структуры. Поэтому пользователь не должен включать указатели в поля структуры: библиотека сохранит значение адреса, а не данные, на которые он указывает.
- Предыдущая полная запись не гарантируется при отключении питания, если новая запись уже перезаписала её байты.
- Перед эксплуатацией необходимы испытания на целевых платах и EEPROM, включая проверку питания во время записи.

## Host-тесты

В tests/host есть тестовая модель памяти и проверки CRC, чтения/записи, восстановления предыдущей записи, циклического перехода, кодов ошибок, проверки записи после записи и компиляции программного I²C.

Запуск из корня репозитория при наличии g++:

~~~sh
sh tests/host/run.sh
~~~
